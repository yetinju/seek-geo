训练软文风格

上传 (.txt / .md / .docx) 软文范文并归入对应分类；在下方「按分类训练」中，可针对每个分类下的范文单独训练，生成该分类专属的「写作风格规范」。之后在「生成器」生成时，系统会自动套用与所选「行文风格」相匹配的分类规范。

上传后，到下方「按分类训练」选择对应分类、点「训练此分类」即可；训练范文会随数据同步到腾讯云 CloudBase（多设备共享）。

API 设置

安全提示：API Key 保存在你浏览器本地缓存，并随业务数据经 Cloudflare 反代同步到 Supabase 云端（用于多设备共享）。当前为匿名共享工作区，任何拿到链接的人都能读取这份云端数据，请勿填写高权限的生产密钥，并仅与可信人员分享链接。本地与云端任一端异常都不会导致 Key 丢失，但请避免与他人共用同一工作区链接。

数据备份

数据会自动同步到 Supabase 云端（多设备实时共享），本地同时以浏览器缓存与 IndexedDB 双重留存。仍建议定期导出 JSON 备份作为额外保险——尤其在重装浏览器、清理缓存或退出匿名工作区前，云端免费项目也可能因长期闲置而暂停。

关于本系统

SeekGeo（GEO 软文工作台）—— 面向 GEO（生成式引擎优化）的一站式内容生产系统。集成「企业画像、企业知识库、文章训练、风格规范、软文库、生成器」六大模块：先沉淀品牌素材与知识，再按八大分类训练范文、提炼专属写作风格，最后一键生成更易被 AI 搜索引擎（ChatGPT / Perplexity / 豆包 / 元宝等）收录与引用的软文。

数据本地以浏览器缓存 + IndexedDB 双重留存，并经 Cloudflare 反代同步至 Supabase 云端实现多设备实时共享；离线时自动降级为本地存储，联网后自动续传。企业知识库已升级为 IndexedDB 持久化，刷新与重启浏览器均不会丢失。系统由 WorkBuddy 构建并托管于 GitHub Pages。
